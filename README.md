# Questões PY — 4º Bimestre

**Autor:** Luiz Eduardo Santos Costa

## Organização
- `ex01.py` até `ex10.py`: um arquivo Python separado para cada exercício.
- Cada arquivo começa com o cabeçalho obrigatório da atividade.

## Como usar
Execute cada exercício separadamente com Python, por exemplo:

```bash
python ex01.py
```

## Envio ao GitHub
Extraia esta pasta e coloque seu conteúdo em um repositório público no GitHub.
A orientação da atividade pede commits individuais conforme cada exercício for concluído.
Exemplo:

```bash
git add ex01.py
git commit -m "feat: conclui o exercício 01"
git push
```

Repita o processo para os demais arquivos.
